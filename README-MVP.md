# Notas do MVP eleitoral

A documentação atualizada do projeto está em [README.md](README.md).

## Status em outubro de 2026

O projeto está no GitHub Pages, usando o Vite com `base: '/observatorio-integridade/'`. A versão 0.2 acrescenta links diretos às candidaturas, um mecanismo público para sugerir correções e validação automática da base eleitoral antes da compilação e publicação.

## Escopo histórico

A fonte eleitoral disponibilizada para este MVP contém 234 candidaturas titulares do PL eleitas em 2022, conciliadas por `SQ_CANDIDATO` entre os dados de candidaturas e o resumo de votação. Não há nesta versão camada pública de processos judiciais nem verificação de todas as retotalizações posteriores.
