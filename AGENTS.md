# Processo de desenvolvimento

Antes de concluir cada entrega ou pull request:

1. Faça code review do diff final: correção, clareza, coesão, duplicação,
   tratamento de erros, compatibilidade, preservação de dados e testes relevantes.
2. Corrija os problemas encontrados e repita as verificações afetadas.
3. Informe o resultado da revisão, a validação executada e limitações restantes.
   Não descreva uma revisão própria como revisão independente.

Preserve fontes e justificativas em alterações documentais. Pesquisa jurídica
não aprovada permanece fora do repositório público. Mudanças de código,
validação estrutural e migrações administrativas não constituem pesquisa nos autos
nem autorização para publicar novas ocorrências.
